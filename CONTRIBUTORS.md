# Pull Requests

**Condemned2Recomp** is in an early stage of development, and I'm prioritizing consistency, existing code, and established project requirements as the codebase evolves.

As a result, pull requests may be declined during this phase, particularly when they introduce changes that conflict with existing implementations, overlook project requirements, or add unnecessary complexity.

I'm keeping contributions limited as I work towards v1.0. **Please consider opening an issue to discuss proposed changes before submitting a PR!!!**

Thanks for your interest!
